# 🐍 Python Öğrenme Yolculuğum

Bu depoda Python öğrenirken aldığım ders notlarını, yaptığım pratikleri ve geliştirdiğim minik projeleri topluyorum.

---

## 📂 Klasör Yapısı

* 📁 **`Dersler/`** : Değişkenlerden fonksiyonlara, decorators konusundan döngülere kadar adım adım ders notlarım (`.ipynb` formatında).
* 📁 **`Projeler/`** : Öğrendiğim konuları pekiştirmek için yazdığım Python uygulamaları.

---

## 🚀 Projeler

* 🎯 **`AdamAsmaca.py`** : Görsel ASCII çizimleri, döngüler ve string işlemleri içeren kelime tahmin oyunu.
* 🧮 **`HesapMakinesi.py`** : Fonksiyonlar ve `if-elif-else` koşul yapıları kullanılarak oluşturulmuş basit hesap makinesi.
